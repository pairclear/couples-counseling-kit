# Промпт: адаптировать домашнее задание

Чтобы адаптировать один из [листов домашних заданий](../homework/) под ситуацию конкретной пары и уровень языка, без данных клиентов.

```text
Адаптируй лист домашнего задания ниже для пары. Не добавляй новых упражнений; сохрани его цель.

Контекст (без имён и узнаваемых деталей): [например «оба работают в ночные смены, двое подростков, ссоры в основном из-за денег»]
Сделай: [короче / проще язык / больше примеров / для одного партнёра]
Сохрани: строку о безопасности, структуру, поля для заполнения.
Не делай: диагнозов, обвинений в адрес одного из партнёров, утверждений об эффективности.

Лист:
[вставьте лист]
```
